Questions, answered

Before you install.

Is Lima free?

Yes. Download the current macOS release directly from this site.

Does Lima require an account?

No. Lima opens directly into your local workspace and does not require a Lima account.

Where is my data stored?

Notes, settings, and workspace data are stored on your Mac. Lima does not provide a cloud workspace or analytics pipeline.

What Mac does Lima support?

The current build supports Apple silicon Macs running macOS 13 or newer.

Can I create extensions?

Yes. Lima supports configurable commands and richer extension interfaces. The complete Extension SDK includes the versioned schema, starter project, examples, and a self-contained AI authoring manual.

How do updates work?

Lima checks this release source for a newer signed build and asks before installing it. You can always download the latest DMG manually.
